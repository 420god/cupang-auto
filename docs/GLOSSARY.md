# 용어집

> **언제 읽나**: 문서나 코드에서 처음 보는 용어가 나올 때. 새 세션 시작 직후 한 번.
> **최종 갱신**: 2026-08-19
> **관련 코드**: `db/migrations/015~022` · `web/js/`

같은 말이 문맥마다 다른 걸 가리켜서 헷갈리는 지점을 모았다.

## 상품 식별자 — 이게 제일 헷갈린다

| 용어 | 무엇 | 어디서 옴 | 자릿수 예 |
|---|---|---|---|
| **바코드** | 쿠팡 발급. **이 시스템의 조인키** | Open API `query-product` | `S0038265161756` |
| **옵션ID** (`vendorItemId`) | 쿠팡이 옵션마다 부여 | Open API / WING | `95827571043` |
| **등록상품ID** (`sellerProductId`) | 판매자가 등록한 상품 단위 | Open API | `16318361249` |
| **상품ID** (`productId`) | 쿠팡 소비자 페이지 URL용 | Open API | `9665014952` |
| **SKU ID** | WING 화면에만 보이는 8자리 | **공식 API 어디에도 없음** | `76795171` |
| **내 SKU** (`my_skus.id`) | 이 시스템 내부 uuid | 우리가 만듦 | uuid |

**바코드가 조인키인 이유**: 쿠팡 발급 = 로켓그로스 입고용 = 쿠플러스 구매요청 입력값 = 구매대행 청구서에 찍혀 나오는 값. **발주·청구서·창고·쿠팡이 전부 같은 번호를 쓰는 유일한 값**이다 → D-02

**형태**: `S00` + `rocketGrowthItemData.sellerProductItemId`

## "묶음"이 두 가지다

| 문맥 | 뜻 |
|---|---|
| **청구서의 묶음** | 1688 **한 판매자에게 낸 한 주문**. 배송비가 하나로 붙는 단위. 같은 상품의 여러 옵션이 한 묶음에 들어간다 |
| **출고 묶음** (`inbound_shipments`) | 한국으로 한 번에 보낸 단위. **여러 발주를 가로질러** 묶인다 |

## 재고·원가

| 용어 | 뜻 |
|---|---|
| **로트** (`inventory_lots`) | 같은 원가를 가진 물량 덩어리. **선입선출의 단위**. 부분 출고하면 쪼개진다 |
| **구매대행분** (`unit_purchase_cost_krw`) | 상품가 + 중국내배송 + 국제운임 + 통관 + 대행수수료. **환율에 전부 포함돼 있다** |
| **작업비** (`unit_work_fee_krw`) | 배대지 검수·포장·바코드. 출고 시 확정. 보통 개당 300원 |
| **개당 원가** (`unit_cost_krw`) | 구매대행분 + 작업비. **이익 계산에 쓰는 값** |
| **미도착** | `qty_ordered − qty_arrived − qty_cancelled` |
| **중국창고** (`qty_china`) | 배대지 창고에 실제로 있는 수량 (도착 − 불량 − 출고분) |

| 이름 | 값(2026-08) | 쓰임 |

| **작업비 환율** | 219.72 | 배대지 작업비·배송비 정산용. 실환율에 가깝다 |

## 회사·서류

| 용어 | 뜻 |
|---|---|
| **쿠플러스 / 쿠패스** | 구매대행사. 1688 대리구매 + 통합통관 + 배대지 운영 |
| **구매대행 청구서** | PDF. 상품별 수량·단가·배송비. **줄 하나 = SKU 하나** |
