```

```

## 틀린 것 ← 다음 세션은 여기부터

**① 화면 주소를 API 주소로 착각했다**
`/tenants/business-insight/sales-analysis`는 **화면** 주소인데 그걸 캡처 경로로 넣어
0건이 나왔다. 실제 데이터는 `/tenants/rfm-ss/api/business-insight/...`였다.
**교훈**: 경로를 추측하지 말고 **전체 요청 목록을 뽑아 거기서 고른다**(R-12).

**② 응답 최상위 키만 훑고 "물류 필드는 없다"고 단언했다**
`rocketGrowthItemData.skuInfo`에 규격·무게·입고명이 **처음부터 다 있었다.**
옵션 최상위 23키만 보고 중첩 안쪽을 안 봤다.
**교훈**: 최상위 키만 훑는 것은 실물 확인이 아니다(R-12).

**③ 워커가 202번 재시작 중인 걸 몰랐다**
주석에 마크다운 강조를 쓰다가 별표 뒤에 `/`가 와서 주석이 조기 종료됐다 → SyntaxError.
증상은 **"등록했는데 아무 데도 안 보인다"**로 나타났다.
**괄호·따옴표는 멀쩡해서 내 검사기가 통과시켰다.**
**교훈**: 서버 코드는 브라우저로 검증 못 한다 — R-13을 그쪽까지 넓혔고 검사기에 세 번째
검사를 넣었다.

**④ 편집 스크립트가 백슬래시를 먹어 네 번 깨졌다**
`\\n`이 실제 개행이 되어 문자열이 안 닫혔다. 확장프로그램에서는 **팝업 버튼이 하나도
반응하지 않는** 엉뚱한 증상이었다.
**교훈**: 히어독으로 백슬래시 든 코드를 넣지 않는다. 파일 도구로 쓴다.

**⑤ 실패를 "받을 게 없음"으로 감췄다**
동기화가 첫 날짜에서 실패하면 `{done:[]}`을 돌려주는데, 팝업이 `done`이 비었는지를
**먼저** 검사해서 "새로 받을 날짜가 없습니다"로 빠졌다.
**내가 계속 경계하던 R-15 유형을 내가 만들었다.**

**⑥ 확인 안 된 것을 화면에 확정처럼 적었다**
"체크 안 하면 저장만 됩니다"라고 써놓고, 정작 그게 WING에서 임시저장인지는 몰랐다.
사용자가 두 번 물어서 알아챘다. (나중에 문서로 확인해보니 맞는 말이었지만,
**그때는 근거가 없었고 근거 없이 단정한 것 자체가 문제**였다)

**⑦ 026을 엑셀 기준으로 짰다가 API와 단위가 어긋났다**
전환율(엑셀 1.71% vs API 0.0171)과 아이템위너(% vs 불리언). 027로 교정.
**교훈**: 같은 개념이라도 출처가 다르면 단위를 검산한다(R-14).
