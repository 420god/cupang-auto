# 소싱 대시보드

쿠팡 상품 데이터를 조회하고 마진을 계산하는 웹 대시보드입니다.

## 파일 구성

```
index.html   화면 구조
style.css    스타일 (다크모드 포함)
app.js       로직
```

빌드 도구가 필요 없습니다. 세 파일만 올리면 동작합니다.

---

## 1. 배포하기 (Vercel · 무료)

가장 간단한 방법입니다. 계정만 있으면 5분이면 됩니다.

### 방법 A — 드래그 앤 드롭

1. https://vercel.com 가입 (GitHub 계정으로 가능)
2. 상단 **Add New → Project** 클릭
3. 아래쪽 **Deploy a template** 옆의 **Browse All Templates** 대신,
   화면에 보이는 **드래그 앤 드롭 영역**에 이 폴더를 통째로 끌어다 놓기
4. 배포가 끝나면 `https://프로젝트명.vercel.app` 주소가 생깁니다

### 방법 B — GitHub 연동 (수정이 잦을 때 편함)

1. GitHub에 저장소를 만들고 이 파일들을 올립니다
2. Vercel에서 **Add New → Project → Import Git Repository**
3. 해당 저장소 선택 → **Deploy**
4. 이후 GitHub에 push하면 자동으로 재배포됩니다

### Netlify를 쓰실 경우

https://app.netlify.com/drop 에 폴더를 끌어다 놓으면 즉시 배포됩니다.
가입 없이도 임시 주소가 나오고, 가입하면 주소가 유지됩니다.

---

## 2. 첫 접속 설정

배포된 주소로 들어가면 로그인 화면이 나옵니다.

1. 아래쪽 **서버 설정** 펼치기
2. **Supabase URL** 과 **Publishable Key** 입력
3. **설정 저장** 클릭
4. 관리자 이메일 · 비밀번호로 **로그인**

설정은 브라우저에 저장되므로 한 번만 하면 됩니다.
기기를 바꾸면 다시 입력해야 합니다.

> **주의** — `secret` 키는 절대 넣지 마세요. 화면에서 자동으로 거부합니다.

---

## 3. 회원 초대

새 사용자를 추가하려면 Supabase SQL Editor에서 이메일을 먼저 등록합니다.

```sql
insert into invited_emails (email, note)
values ('새사람@example.com', '메모');
```

등록된 이메일로만 회원가입이 됩니다.
가입한 사람은 공통 데이터를 볼 수 있고, 자기 소싱 데이터만 따로 관리합니다.

---

## 4. 화면 안내

### 소싱

수집된 상품 목록입니다. 스크롤하면 계속 불러옵니다.

- **행을 클릭**하면 옵션이 아래로 펼쳐집니다
- 옵션 행에서 **원가(¥)** 를 입력하면 마진이 즉시 계산됩니다
- **희망가** 를 넣으면 그 가격 기준으로 다시 계산됩니다
- **사이즈** 를 바꾸면 입출고비가 다시 조회됩니다
- 입력값은 자동 저장되며, 수집을 다시 해도 지워지지 않습니다
- 상품 행의 마진율·마진액은 **옵션 중 가장 높은 값**을 보여줍니다

### 즐겨찾기

별표를 누른 옵션들이 모입니다.
상태(검토중 / 소싱대기 / …)를 바꾸고 메모를 남길 수 있습니다.
상단 탭으로 상태별 필터링이 됩니다.

### 카테고리

대분류별로 묶여 있고, 헤더를 누르면 펼쳐집니다.

| 색 | 뜻 |
|---|---|
| 초록 | 오늘 2단계까지 완료 |
| 파랑 | 오늘 목록만 수집 |
| 노랑 | 과거에 수집 |
| 회색 | 미수집 |

카테고리를 클릭해 선택한 뒤 **수집 요청** 을 누르면 대기열에 등록됩니다.
별표를 누르면 즐겨찾기 카테고리가 되고, 소싱 화면에서 필터로 쓸 수 있습니다.

### 수집 대기열

웹에서 등록한 요청 목록입니다.
확장프로그램이 이 목록을 읽어 수집하고 결과를 올립니다.

---

## 5. 알아두실 점

**수집은 확장프로그램이 합니다.**
웹사이트는 쿠팡 로그인 세션에 접근할 수 없어, 직접 수집할 수 없습니다.
웹에서는 "무엇을 수집할지" 등록하고, 확장프로그램이 그 요청을 처리합니다.

**설정값은 개인별로 저장됩니다.**
환율·기본 비용·수수료율은 사용자마다 따로 관리됩니다.
이미 입력한 상품의 환율은 나중에 설정을 바꿔도 그대로 유지됩니다.

**입출고비는 요금표가 있어야 계산됩니다.**
확장프로그램에서 "요금표 수집 → 요금표 업로드"를 먼저 실행해주세요.
요금표가 없으면 입출고비가 0으로 계산됩니다.
