브랜드 · 제조사 · 카테고리 · 조회수를 가져옵니다

준비 중인 상품이 없습니다 — 소싱 → 즐겨찾기에서 [등록 준비]를 누르거나, 상품등록 화면에서 새로 만드세요.

확장프로그램이 WING 세션으로 대신 조회합니다. 사람이 누를 때만 1회씩 부릅니다 — 자동으로 반복 호출하지 않습니다.

상세페이지

세트 단위로 고릅니다 · 한 장짜리 긴 이미지도 됩니다

준비 중인 상품이 없습니다 — 소싱 → 즐겨찾기에서 [등록 준비]를 누르거나, 상품등록 화면에서 새로 만드세요.

여러 장을 한 번에 올리면 한 세트가 됩니다. 고른 순서가 곧 노출 순서입니다. 세트를 여러 벌 만들어두고 세트 통째로 골라야 "A안에서 B안으로 바꿨더니 전환율이 어땠나"를 나중에 판정할 수 있습니다.
상세페이지를 바꾸면 구매전환율·장바구니를 봅니다 — 조회는 안 변하는 게 정상입니다.
