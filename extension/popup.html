상세 보강을 쓰려면 www.coupang.com 탭도 하나 열어두세요.
선택 0 / 전체 0 말단만 전체선택 전체해제
수집량이 많아 시간이 오래 걸립니다. 창을 닫으면 중단되니 별도 창으로 열기를 쓰세요. 데이터는 계속 저장되어 중단해도 그때까지 받을 수 있습니다.
수집 옵션
상위 N이 0이면 전체입니다. 기본적으로 상세 보강 대상에만 적용됩니다.
5개 신호(응답추세 · 서버첫응답 · 방어쿠키 · 리다이렉트 · 능동탐침)로 4단계 경보를 판정합니다. 주의는 간격 완화, 경고는 동시 수 감소, 위험은 60초 냉각, 차단은 장기 정지로 대응합니다. 분당 상한은 동시 수와 무관하게 지켜지는 절대 한도입니다. 안전을 원하면 시작 1 · 최대 3 · 분당 30을 권장합니다.
이미지 크기
엑셀과 구글 시트는 IMAGE 함수 형식이 서로 다릅니다. #VALUE! 오류가 뜨면 "양쪽 호환"을 선택하고, 행 높이·열 너비로 크기를 조절하세요.

원본 화질은 받아올 이미지 해상도입니다. 크게 잡을수록 선명하지만 느려집니다.
셀 표시는 픽셀 지정 모드에서만 적용되며, HTML 갤러리에는 항상 반영됩니다.
사전 필터 (상세 조회 대상 줄이기)
상품 수집 결과 중 조건에 맞는 것만 상세 조회합니다. 0이면 제한 없음입니다.
데이터베이스 저장 (Supabase)
수집한 데이터를 웹 데이터베이스에 저장합니다. secret 키는 절대 넣지 마세요. publishable 키만 사용합니다.
"② 전체 카테고리 불러오기" 후 누르면 카테고리 트리 전체가 웹사이트에 등록됩니다. 한 번만 하면 되고, 카테고리가 개편될 때만 다시 하면 됩니다.
대기열 자동 처리
웹사이트에서 등록한 수집 요청을 30초마다 확인해 자동으로 처리합니다. 이 창을 열어두어야 동작하므로 "별도 창으로 열기"를 권장합니다.
업로드는 덮어쓰기(upsert) 방식입니다. 같은 상품은 최신 값으로 갱신되고, 변경 이력은 하루에 한 번만 기록됩니다. 개인 소싱 데이터(원가·메모·즐겨찾기)는 업로드가 건드리지 않습니다.
입출고비 계산
상세수집이 끝나면 해당 카테고리의 정가/할인가 요금표(극소형~특대형)와, 있다면 14,000원 미만 저가 상품 전용 할인가(전용할인가) 표까지 자동으로 받아 수집 데이터 업로드 때 같이 올립니다. 이미 DB에 있는 카테고리는 다시 받지 않습니다. 웹사이트는 전용할인가가 있으면 그걸 우선 쓰고, 없으면 일반 할인가를 씁니다.
사용법
평소엔 아무것도 안 눌러도 됩니다 — 상세수집 후 자동 수집·자동 업로드됩니다.
아래 버튼은 수동으로 다시 모으거나 엑셀용 CSV가 필요할 때만 씁니다.
상세 보강 단독 실행
이미 수집한 상품 데이터에 판매량·배송유형만 따로 보강할 때 사용합니다.
형식: productId,itemId,vendorItemId (itemId부터 생략 가능)
